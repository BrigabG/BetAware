# Documentos de la materia

Esta carpeta guarda los documentos de la cátedra y del equipo que usamos para revisar el juego.

Subir acá:

- Consigna o enunciado del trabajo práctico.
- Rúbrica o criterios de evaluación.
- Documento de diseño del juego (GDD) y entregas anteriores.
- Investigación sobre apuestas y ludopatía, con sus fuentes.
- Resultados de playtests y devoluciones de la cátedra.

Formatos que se pueden leer: PDF, DOCX, PPTX, XLSX, Markdown y texto plano. Si un documento está en Google Docs, descargarlo con *Archivo → Descargar* antes de subirlo.

Conviene que el nombre de cada archivo diga qué es, por ejemplo `consigna-tp-final.pdf` o `rubrica-evaluacion.pdf`.
